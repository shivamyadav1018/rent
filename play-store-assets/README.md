# KirayaBahi Google Play assets

The `upload-ready` folder contains the graphics prepared for the Google Play listing:

- `app-icon-512x512.png` — 512 × 512 PNG app icon.
- `feature-graphic-1024x500.png` — 1024 × 500 PNG feature graphic.
- `phone-screenshots/*.png` — five 1080 × 1920 portrait listing images.

The screenshots combine original campaign artwork with UI panels reconstructed from the current KirayaBahi design and feature set. They do not show the unrelated legacy app that had previously occupied the emulator package ID.

## Recommended ASO copy

**App name (30 characters maximum)**  
KirayaBahi: Rent Manager

**Short description (80 characters maximum)**  
Track rent, tenants, payments, reminders and receipts—even offline.

**Opening long-description copy**  
Manage properties, tenants and monthly rent without messy notebooks. KirayaBahi is an offline-first rent manager for landlords, with payment tracking, partial payments, rent reminders, tenant records and professional PDF receipts.

**Primary keyword themes**  
rent manager, rent tracker, landlord app, tenant management, rent ledger, rent receipt, payment reminder, property management, offline rent app, kiraya hisab
